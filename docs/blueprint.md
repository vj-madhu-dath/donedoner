# **App Name**: DoneDoer

## Core Features:

- Task Input: Allow users to input completed tasks as text.
- Task Display: Display the list of added tasks to the user in a readable list.
- Task Completion: Allow users to mark tasks as 'done' via a checkbox or similar.
- Completed Task Styling: Apply visual styling to completed tasks to differentiate them from pending tasks (e.g., strikethrough, change color).
- Task Storage: Persist tasks using local storage to survive page refresh.
- AI Powered Habit Suggestions: Generative AI suggest a new task for users, which LLM can "tool" itself by analyzing previous added tasks. 

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) for a calm and accomplished feel.
- Background color: Light Gray (#F5F5F5) to ensure readability and a clean interface.
- Accent color: Muted Purple (#A9A9D1) to highlight interactive elements.
- Font: 'PT Sans', a sans-serif font for a clear, modern, and easily readable style. This will apply for headlines and body text
- Use simple, line-based icons for task status (e.g., a checkmark for 'done').
- Employ a clean and minimalist layout, focusing on task list clarity. Use white space effectively.
- Provide subtle animations upon task completion (e.g., a gentle fade or slide).
